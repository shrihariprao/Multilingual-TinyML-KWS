# Dashboard Images

High-resolution graphics for the Multilingual TinyML Keyword Spotting prototype.

- `01_project_overview.png`: project overview and evaluation summary
- `02_performance_by_language.png`: language-wise accuracy and family-disjoint metrics
- `03_error_analysis.png`: family-disjoint confusion matrix and per-command F1
- `04_deployment_readiness.png`: model footprint and remaining validation gates

These figures are based on saved evaluation reports. Results are preliminary and use synthetic
samples. Native-speaker validation and physical-device latency and energy measurements remain
outstanding.
